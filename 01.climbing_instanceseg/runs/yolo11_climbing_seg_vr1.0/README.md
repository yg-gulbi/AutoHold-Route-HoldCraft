# yolo11_climbing_seg_vr1.0

YOLO11m-seg 기반 등반 홀드 인스턴스 세그멘테이션 1차 학습 기록입니다.

## 핵심 요약

- **모델**: YOLO11m-seg (Instance Segmentation)
- **데이터셋**: Roboflow `hold_seg_data` v1
- **전체 이미지**: 3,389장
- **클래스**: `Hold` (일반 홀드), `Volume` (볼륨 홀드)
- **주요 성과**: Bounding Box $mAP_{50}$ 85.7%, Mask $mAP_{50}$ 81.5%
- **개선 방향**: Recall 80.8%를 높이기 위한 서버 후처리 기반 TTA 적용 검토

## 1. 데이터셋 및 학습 환경

- **데이터 출처**: [Roboflow `hold_seg_data` v1](https://app.roboflow.com/-jbsag/hold_seg_data/1)
- **Train Set**: 1,936장 (57%)
- **Valid Set**: 1,453장 (43%)
- **Test Set**: 별도 분리 없음 (0장)
- **데이터 상태**: 회전 및 구도 변화 등 원천 이미지에 대한 사전 후처리가 적용됨
- **모델 초기 가중치**: `yolo11m-seg.pt`
- **이미지 크기**: 640
- **Batch size**: 16
- **Epochs**: 100
- **Early stopping patience**: 20

데이터셋은 Roboflow에서 내려받아 사용하며, 용량과 GitHub 파일 크기 제한을 고려해 저장소에는 포함하지 않습니다.

## 2. 1차 학습 성능 지표

| 평가 항목 | 지표 | 측정값 |
| --- | --- | ---: |
| Box Detection | `box_map50` | 0.8568 (85.7%) |
| Box Precision | `precision` | 0.8834 (88.3%) |
| Box Recall | `recall` | 0.8081 (80.8%) |
| Box Strict | `box_map50_95` | 0.6976 (69.8%) |
| Segmentation Mask | `seg_map50` | 0.8149 (81.5%) |
| Segmentation Strict | `seg_map50_95` | 0.5504 (55.0%) |

상자 탐지 Precision은 88.3%로 오탐지 억제가 양호하지만, Recall은 80.8%로 일부 홀드를 놓치고 있습니다. 특히 높은 IoU 기준의 Mask $mAP_{50:95}$가 55.0%이므로 복잡한 형태의 `Volume`과 작은 `Hold`의 경계 추출에는 개선 여지가 있습니다.

## 3. 1차 프로젝트 회고

### 데이터셋 파악 및 검증 미흡

학습 전에 데이터셋의 구성과 Roboflow에서 적용된 전처리·증강 상태를 충분히 분석하지 못했습니다. 그 결과 전처리와 증강이 학습 및 성능 지표에 미친 영향을 해석하는 데 한계가 있었습니다.

### 독립적인 Test Set 부재

이번 데이터셋은 Train과 Valid만 사용했으며, 학습과 검증에 관여하지 않는 독립적인 Test Set을 확보하지 못했습니다. 따라서 현재 지표만으로는 실제 환경에서의 일반화 성능을 완전히 판단하기 어렵습니다.

## 4. 2차 파이프라인 및 학습 계획

1. 추가 데이터를 확보해 파인튜닝을 진행합니다.
2. Train 70%, Valid 15%, Test 15%와 같이 독립적인 Test Set을 분리합니다.
3. Roboflow 적용 전처리와 증강 항목을 명시적으로 기록하고 통제합니다.
4. `Hold`와 `Volume`의 클래스별 비율과 AP를 따로 확인합니다.

### 서버 후처리 기반 커스텀 TTA 및 임계값 최적화

실시간 추론 제약이 없는 서버 후처리 환경을 활용해, 하나의 입력 이미지에 다음 세 가지 변환을 적용해 추론하는 방안을 검토하고 있습니다.

- 원본 이미지
- 밝기 +20% 이미지
- 밝기 -20% 이미지

각 결과를 NMS로 병합해 누락된 홀드를 보완하고, Recall을 현재 80.8%에서 88% 이상으로 높이는 것이 목표입니다. 다만 TTA 결과를 단순히 합치면 오탐지가 증가할 수 있으므로, 병합 과정의 `conf` 임계값과 NMS 매개변수를 함께 최적화해 Precision 손실을 최소화할 계획입니다.
